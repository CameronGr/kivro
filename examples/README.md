# Examples

| Directory / file        | Shows                                                           |
| ----------------------- | --------------------------------------------------------------- |
| `rust-app/`             | Loading secrets through the library API, plus a readiness check |
| `node-app/`             | `kivro run` in npm scripts and a `--json` readiness gate        |
| `Makefile`              | Gating a build on `kivro status`                                |
| `ci-github-actions.yml` | Populating a store in CI and running tests                      |
| `kivro.example.toml`    | A fully annotated manifest                                      |

Every example assumes `kivro` is on `PATH`.
